# Demo / 端到端示例（制作中）

本目录将存放一次**完整的端到端运行记录**：从拿到赛题，到产出一份可提交的论文。目标是让没装过本技能包的人 10 分钟内判断"这套 skill 到底能产出什么"。

## 计划内容

| 子目录 | 内容 |
|---|---|
| `problem/` | 赛题原文（官方公开 PDF）与数据说明 |
| `runs/` | 求解代码、运行日志与 SHA-256 清单（演示可复现性） |
| `figures/` | 论文关键图表 |
| `paper.pdf` | 最终论文（匿名格式，与正式提交版式一致） |

## 选题与验收标准

- 选题：一道 CUMCM 历年真题（数据公开、可完整复算）。
- 产出与正式参赛同标准：官方 LaTeX 模板、`math-modeling-pro` 全部质量门通过（三层一致性机检、匿名性检查、提交前独立审计）。
- 全程记录触发语与 Agent 交互过程，作为"怎么用"的活教材。

完成后本节将更新为实际产物链接与运行要点。

# 工作流检查点

| Stage | 退出条件 |
|---|---|
| 1 题目与数据 | 全部附件读取状态明确，数据审计、语义确认和交付契约完成 |
| 2 证据与模型 | 主模型、基线/消融、假设、数量级、贡献证据和失败判据明确 |
| 3 实现与求解 | 程序实际运行，独立验证/适用的收敛性或不确定性检查、领域质量门、格式和重复运行通过 |
| 4 论文 | 所有关键数字可追溯，贡献表述有证据，反模板化审读、引用、图表、附录和匿名性静态检查通过 |
| 5 编译与视觉 | 双遍编译，目标日志警告清零，关键页面视觉与文本完整性通过 |
| 6 提交验收 | 最终 ZIP 隔离复现，环境清单、PDF/ZIP/属性/大小/哈希和带版本记录的当届规则核验通过 |

任何 Stage 3 硬门失败都回退模型或实现；不得用论文措辞掩盖异常结果。

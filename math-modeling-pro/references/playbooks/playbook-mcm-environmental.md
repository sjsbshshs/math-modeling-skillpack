# 美赛 E 题：环境科学与生态建模

## 匹配条件
- 特征词："环境""生态""物种""种群""食物链""可持续发展""碳排放""气候""自然灾害""污染""保护""保险"
- 比赛类型：美赛 MCM/ICM
- 题目类型：E
- 数学本质：生态系统建模 + 环境评估 + 优化/政策

## 方法选择决策树

先判有无时间动态、空间异质性是否必须保留，再定参数来源、情景设计与外推边界。

```
研究对象的量随时间变化吗（增长率、排放、存量、种群规模）？
├─ 是 → 必须用微分方程或差分方程（ODE、Lotka-Volterra、房室模型、状态转移）
│        禁用静态回归去拟合带时间趋势的序列：会得到伪回归与虚假显著
│        先定积分器与步长，再做步长减半校验
├─ 否，但存在空间分布差异 → 空间分区或网格模型
│        先说明分区依据（气候带、流域、土地利用类型）与分区数量对结论的影响
└─ 否，且空间可平均 → 集总式统计模型（回归 / 评价指标 / 成本效益分析）
         但仍须讨论"平均值掩盖了哪些极值区域"

空间异质性必须保留吗？
├─ 必须（政策按区落地、极值区域决定风险）→ 分区或网格化，逐区给参数与结果
└─ 不必（只问总量或全域尺度）→ 集总式，但需做一次分区对照证明集总不失真

模型参数从哪里来（逐个交代，不许含糊）？
├─ 文献值 → 标注来源（作者 / 年份 / 适用对象），并检查能否迁移到本题区域
├─ 数据拟合 → 给出拟合方法与置信区间，说明数据覆盖的时间与空间范围
└─ 经验估计 → 必须做敏感性分析，并明确标注是"估计值"而非"文献值"
    参数不确定度大时，单因素扫描是最低要求；有条件再做全局敏感性（Sobol / Morris）

是否需要政策情景对比？
├─ 是（补贴、限排、保护区面积、保险费率）→ 多情景模拟 + 指标面板
│        情景必须可执行（给出参数取值与生效时点），并保留基线情景作对照
│        情景间差异用同一套指标口径，禁止换情景就换指标
└─ 否 → 单情景预测，但仍须给出不确定区间

是否要外推未来（预测年份超出数据范围）？
├─ 是 → 声明外推边界：哪些参数假设不变、假设何时失效
│        给出不确定性区间（参数区间传播到输出），禁止只给一条曲线
└─ 否 → 内插或现状评估，报告与观测数据的拟合优度
```

## 失败判据卡

每条都是**可执行断言**。任一断言失败，先修模型或实现，不得带着异常结果进论文。

| # | 断言 | 判据 | 失败时先查 |
|---|------|------|-----------|
| 1 | 量纲一致 | 每个方程、每个指标逐项标注单位，两侧量纲相同；换算系数（t 与 kg、亩与 ha、年与秒）逐个写出 | 是否把不同单位的量直接相加；时间单位换算是否漏乘 |
| 2 | 守恒或质量平衡闭合 | 收支闭合：流入 − 流出 = 存量变化，残差相对误差 < 1e-6 | 是否漏了汇项（降解、迁出、泄漏、收获） |
| 3 | 参数来源逐个标注 | 无来源参数个数为 0；每个参数带来源标签（文献 / 拟合 / 估计）与取值区间 | 是否把"看起来合理"的数直接写进模型 |
| 4 | 参数敏感性已完成 | 至少完成单因素扫描，给出输出对各关键参数的变化率排序 | 是否只对最不确定的那一个参数做了分析就称"已做灵敏度" |
| 5 | 数值解可靠 | 步长或网格减半后关键输出相对变化 < 1e-3，且报告所用积分器与容差 | 刚性方程是否用了显式方法导致发散，却当成生态突变 |
| 6 | 与观测一致 | 状态变量与观测数据逐时段对比，给出拟合优度或相对误差，并指出偏差最大的时段或区域 | 是否只画曲线不量化偏差 |
| 7 | 外推边界已声明 | 预测超出数据范围时，逐条列出"假设不变的量"与假设失效的临界条件 | 是否把趋势外推当作既成事实写进结论 |
| 8 | 不确定性区间齐全 | 关键结论给出区间（参数区间传播或 Monte Carlo 分位数），不只给点估计 | 是否只报了一条均值曲线 |
| 9 | 情景可比 | 各情景用同一套指标口径与同一时间轴，基线情景存在且可实现 | 对照情景是否被设成"必赢"的极端值 |
| 10 | 政策建议可执行 | 每条建议给出作用对象、量化力度与生效时点，可被第三方按同一模型复算 | 是否停留在"应加强保护"式表述 |

## 解题示例（一种可行路径）

### Step 1：生态系统机制建模
构建食物链/食物网模型（Lotka-Volterra 或 Holling 功能响应），或碳/水循环模型，或极端事件统计模型。E 题核心是"理解自然系统的数学规律"。

### Step 2：数据处理与参数估计
从题目数据或文献中提取关键参数（物种增长率、捕食率、碳排放因子等）。善用文献综述补充参数（这是美赛加分项）。

### Step 3：多情景模拟
设置不同情景（如不同气候情景 RCP 4.5/8.5，不同政策力度），用 Monte Carlo 或 ODE 数值求解模拟长期演变。

### Step 4：构建评价指标体系
设计生态健康/可持续性/经济影响等指标。常用 Shannon-Wiener 多样性指数、生态系统服务价值、成本效益比。

### Step 5：优化与政策建议
基于模拟结果，优化政策参数（如补贴力度、保险定价、保护区面积）。输出具体可操作的建议。

### Step 6：可迁移性检验
将模型应用到另一个区域/生态系统，验证通用性（美赛标配）。

## 关键陷阱
- **生态模型过于简化**：单用 Lotka-Volterra 而不考虑环境承载力、年龄结构等多因素
- **参数无出处**：生态参数不能瞎编，必须引用文献或从数据估计
- **忽略反馈循环**：生态系统有正负反馈，单向因果链不够
- **政策建议太空泛**：必须给出具体数值（如"建议补贴 $X/亩"），不能只说"应该加强保护"
- **忘记 Letter**：E 题必须写给农民/社区/决策者的信

### 方法应用史走查：气候风险与财产保险建模（原 2024 MCM E 题型）

> 本节为历史题的方法结构演示，仅说明"题目拆解 → 模型选择 → 公式 → 代码 → 结果解读"应达到的完整度。禁止在新论文中复刻其章节结构、参数取值、图表布局或结论表述；评审会将高度同构的解法视为背题。

参考论文：E_2401102, E_2410889

### 题目拆解
- 问题一（保险定价模型）：统计/预测 — 基于历史极端天气数据建立保险精算模型
- 问题二（需求-风险均衡）：优化 — 在保险公司利润和居民可负担性之间找平衡
- 问题三（政策建议）：决策 — 提出具体的保险方案和风险分担机制

### 模型选择
论文使用了以下模型（注意美赛命名风格）：
- **AFC/LFC 保险定价模型**（Lane's model）：精算定价核心
- **Cobb-Douglas EER 计算**：经济-环境-风险三元效用函数
- **DEMI 模型（Demand-Risk Equilibrium Model for Insurance）**：双目标优化（需求最大化 vs 风险最小化）
- **Marshallian 需求曲线**：分析价格对保险购买意愿的影响
- **ARIMA 模型**：极端天气频率预测

### 核心公式
Lane's AFC 保险定价：
$$P = E[L] + \lambda \cdot \sigma(L)$$
其中 $E[L]$ 为期望损失，$\sigma(L)$ 为损失标准差，$\lambda$ 为风险载荷因子。

DEMI 双目标优化：
$$\max_{p} \quad \alpha \cdot D(p) - (1-\alpha) \cdot R(p)$$
其中 $D(p)$ 为保险需求函数，$R(p)$ 为风险敞口，$\alpha$ 为社会偏好权重。

### 代码思路
1. **ARIMA 极端天气频率预测**：用 `statsmodels.tsa.arima.model.ARIMA` 拟合历史频率数据，预测未来 10 年各等级极端事件的年发生次数
2. **Monte Carlo 损失分布模拟**（10,000 次）：
   ```
   Algorithm: Monte Carlo Loss Simulation
   Input: 极端事件频率分布, 损失程度分布(对数正态), 地理暴露数据
   Output: 年总损失的经验分布
   Steps:
   1. for trial = 1 to 10000:
   2.     对每个区域，从频率分布抽样年事件次数 n
   3.     for each event:
   4.         从对数正态分布抽样单次损失 severity ~ LogNormal(mu, sigma)
   5.         累积：total_loss[region] += severity * exposure_factor
   6.     汇总全国年总损失 = sum(total_loss)
   7. 计算 VaR(95%) 和 CVaR(95%) 作为尾部风险指标
   8. return 损失分布, VaR, CVaR
   ```
3. **Pareto 前沿求解**：对每个保费档位 p ∈ [100, 500]，计算需求 D(p) 和风险 R(p)，绘制 D(p)-R(p) 散点图，标记 Pareto 前沿点
4. **可迁移性检验**：将模型参数从 Florida 替换为 California 后重新运行全部模拟，对比两次结果的一致性

### 关键参数获取
| 参数 | 典型值 | 来源 |
|------|--------|------|
| 极端事件年发生率 | 0.5-3.0 次/年 | NOAA 历史数据拟合 |
| 损失严重度中位数 | $50K-$500K | FEMA 保险理赔数据库 |

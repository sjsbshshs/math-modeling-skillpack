# 模型质量门与否决规则

本文件在 Stage 2 定义失败判据、Stage 3 验收模型时使用。质量门的目标是尽早否决“程序能跑但模型错误”的方案。

## 最小必做集与扩展集

竞赛时间内资源有限，验证按两层执行；硬门（下一节）不受分层影响，永远必做。

**最小必做集**（每个子问题，无论时间多紧都必须完成）：

1. 约束残差复算：对最终解重新计算全部硬约束、守恒或不变量。
2. 一个基线对比：常数预测、贪心、线性模型或解析简化中选与本问题最贴切的一个。
3. 数量级与边界检查：关键结果与题目数据、物理常识或简单上/下界对照。
4. 输出格式一致性检查：结果文件满足题目指定的模板、字段、精度和命名。
5. 论文↔结果数值一致性：进论文的每个关键数字登记进结果摘要并经脚本从结果文件复现；编译后对 PDF 复验（`scripts/check_paper_consistency.py`，细则见 `paper-consistency.md`）。实现级检验全部通过不代表论文里的数字正确——错位数据依然自洽。

**扩展集**（有时间才做，跳过必须在论文中如实披露检验范围）：

- 参数灵敏度和关键假设情景分析。
- 独立实现、交叉算法或收敛性验证。
- 输入不确定性传播（蒙特卡洛等）与结果稳健性。
- 重复运行统计与多次运行分布报告。

扩展集做不完时，论文只能声称已验证的结论；不要为了声称“鲁棒性强”而临时赶工低质量检验。

## 通用硬门

以下任一项失败时，不得进入论文写作：

1. 输出缺失、非有限值、单位不一致或违反题目明确边界。
2. 硬约束、守恒、不变量或逻辑规则超过预先声明的数值容差。
3. 关键结果比朴素上/下界差，且无可解释原因。
4. 重复运行在相同输入和随机状态下产生不可解释的不一致。
5. 结果文件没有满足题目指定的模板、字段、精度或命名。
6. 使用了未提供、未说明或无法随交付物复现的数据和依赖。

## 建模前先写失败判据

对每个子问题记录：

| 项目 | 内容 |
|---|---|
| 预期量纲和数量级 | 根据单位、物理范围、样本统计或简单上界估计 |
| 必须满足的不变量 | 守恒、概率和为1、流量平衡、库存平衡、几何连续等 |
| 题目语义级不变量 | 至少 1 条/子问题：由题目语义直接推出、与实现无关的关系（位移≈速度×时间、起点在给定边界、终值与声称值一致等），写成可执行断言登记进结果摘要的 cross_checks；实现级残差通过不代表它成立 |
| 基线 | 常数预测、最短路、贪心、线性模型、解析简化或人工小样例 |
| 极限情形 | 参数趋零、趋大、无约束、单源/单目标或对称情形 |
| 可接受容差 | 数值残差、预测误差、最优性间隙或业务容差 |
| 关键假设 | 会改变结论的边界、分布、权重、流向或行为规则 |

## 按题型选择验证

### 预测、分类与统计

- 划分训练/验证/测试，时间数据按时间顺序切分。
- 所有预处理、特征选择和调参仅在训练折内拟合，防止泄漏。
- 与朴素模型比较；给出均值和波动，不只给最好一次。
- 检查残差、类别不平衡、校准或统计假设，选择与任务匹配的指标。

### 优化与调度

- 对最终解重新计算全部约束残差和目标函数。
- 小规模实例使用枚举、精确求解器或人工解交叉验证。
- 报告停止条件、随机种子、多次运行分布和相对基线提升。
- 只有精确证明或可验证证书时才称全局最优；否则称当前最好可行解。

### 机理、ODE/PDE与仿真

- 做量纲分析、守恒闭合、边界/初始条件和稳定性检查。
- 与解析解、已知极限、网格/步长收敛或简化场景比较。
- 区分舍入/离散误差与结构/参数不确定性。
- 对主导结论的边界条件和机理假设做开关情景或敏感性分析。

### 评价与排序

- 检查指标方向、量纲、正向化和标准化。
- 说明权重来自数据、专家还是政策，不得凭空赋权。
- 改变标准化、权重或缺失处理，检查名次稳定性。
- 高相关指标需合并、降维或解释重复计权的合理性。

### 网络与路径

- 检查连通性、重复边、自环、方向、容量和特殊点投影。
- 小图上与枚举或成熟算法比对；核验路径的每条边和时间单调性。
- 时变网络必须处理途中状态变化，不能默认静态边权。
- 流/传播模型检查节点与总体守恒，必要时测试回流、汇流和多源异步事件。

## 结果分级

- **通过**：全部硬门通过，关键假设已做情景或敏感性检查。
- **条件通过**：数值与交付硬门通过，但存在明确的数据/机理边界；论文必须披露。
- **否决**：硬门失败或关键结果不能复现。回退模型、数据处理或实现，不得通过改写论文掩盖。

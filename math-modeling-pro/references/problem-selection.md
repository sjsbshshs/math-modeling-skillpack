# 国赛本科组选题决策（Stage 0）

先读取 `official-compliance.md` 并复核当届官网。**本文件是先验参考，不是规则，也不得据历史题的解法、参数或结论作答。**

## 为什么单独设这一阶段

SKILL 的流程原本从「题目与数据审计」开始，默认题已选定。但国赛本科组是 A/B/C 三选一，这个决策在开赛首日做出，决定后续全部 72 小时的走向。选题错的代价不是多花时间，而是**后续所有质量门都作用在错误的骨架上**——发散、建模、验证、写作全都在为一道不该选的题服务。

本阶段是全流程中唯一「成本极低、杠杆极高」的环节：2 小时的投入，决定 70 小时的产出方向。

## 一、题号的性质：无官方定义，可信度有限

国赛 A/B/C **没有官方题型定义**（mcm.edu.cn 历届规程与通知中均未发布；网络流传的「A 机理、B 优化、C 数据」是经验归纳，非官方口径）。

题号的正确用途是**选题先验**，不是**路由键**。后者请按数学结构判断，见 `model-selection-matrix.md`。两者的区别见下文第三节——这个区别在 2025 年被真实数据验证过。

**与 `paper-guides/problem-type-strategies.md` 的分工**（两份文件都谈题号，但用途相反，不要混用）：

| | 本文件 | `problem-type-strategies.md` |
|---|---|---|
| 回答什么 | **选哪道题** | 选定之后**怎么写、怎么求解** |
| 用在哪个阶段 | Stage 0（开赛首 2 小时） | Stage 4 写作、Stage 3 求解 |
| 对题号的立场 | 弱先验，须按第三节分层使用 | 经验归纳，已多次失效，仅用于校准写作重心 |
| 误用后果 | 用题号预判题型 → 选错题 | 用题号选路线 → 硬套错误流程 |

读完本文件选定题之后，才去读 `problem-type-strategies.md` 对应题号那一节，并且**先确认当年的题确实属于该类**。

## 三、规律强度分层（本文件核心结论）

归纳上表，三道题的可预测性**差异极大**，不能同等对待：

**C 题 · 规律强（可作先验）**
五年均为「**数据驱动 + 优化决策**」双段结构：先从数据建立映射或规律，再在其上做决策优化。推论：C 题只做统计分析不做优化决策，等于只完成一半，这也是 C 题最常见的失分形态。

**A 题 · 规律中等（先验会漂移）**
五年均为「**物理/几何建模 + 优化**」，但内核在迁移：2021–2022 偏场与方程，2023–2025 转向运动学与几何约束。**按「备战 PDE 数值解」的思路准备 A 题会错位。**

**B 题 · 基本无规律（不要用题号预判）**
五年五种数学本质：实验设计回归 → 几何定位 → 几何覆盖 → 统计决策 → 光学反演。B 题承担的是「综合题」定位，是命题组放置不按套路题目的位置。**任何「B 题应该是 X」的预设都会在选题时误导你**——2025 年出光学物理题即为实证。

**直接推论：选题决策必须读完三道题的题面全文后再做，不得凭题号预判。**

## 四、决策清单（逐题回答，不看题号看这六项）

对每道候选题回答以下六项：

1. **数学本质**：识别 1–3 个结构原子（动力系统 / 组合优化 / 连续优化 / 网络图 / 统计推断 / 评价决策 / 随机过程 / 博弈 / 几何运动 / 模式发现）。
2. **数据可得性**：附件数据是否足以支撑建模？是否需外部数据（外部数据须可核验并在论文注明来源与获取日期）？
3. **队伍能力**：三人中是否至少一人具备该题核心方法的**实战经验**（不是「学过」）？
4. **可验证性**（关键，直接决定 `quality-gates.md` 能否通过）：该题是否存在至少一类真值、守恒量、解析极限、小样例或基线可供比对？**一道完全无法验证的题，结果正确性门必然过不了。**
5. **求解规模**：在 72 小时预算内，最大规模算例能否算完？是否需规模缩减（缩减须在论文声明）？
6. **区分度风险**：这题是否「人人都会做」？若是，你的增量在哪里（对应 `innovation-mechanisms.md` 机制二的特殊结构识别）？

## 五、发散预演（把机制一接入选题）

按 `innovation-mechanisms.md` 机制一，对每道候选题花约 5 分钟做**建法预演**：不查任何资料，只想「这道题可以怎么建」。

- 想不出 2 个以上**本质不同**的建法 → **不选**。这说明队伍在该题上缺乏发散空间，后续机制一很难通过。
- 这条同时是选题阶段的止损点：它比「看起来熟不熟悉」可靠得多。

## 六、常见陷阱

1. **题面熟 ≠ 好做**。看似常规的题常把区分度藏在非显然处（如 2024 C 题的区分度在风险度量，而非种植模型本身）。
2. **数据给得多 ≠ 简单**。数据量大的题，成败在数据审计与清洗，不在模型。
3. **A 题不等于 PDE**。连续三年 A 题是运动学/几何约束 + 优化。
4. **B 题不要预设**。见第三节。
5. **三题都像时，选可验证性最强的**。在结果正确性设有硬门的流程里，可验证性是权重最高的安全垫。

## 七、时间盒与产物

- **时间盒**：开赛后不超过 **2 小时** 完成选题。超时则按第四节第 4 项选可验证性最强者，不再比较。
- **产物**（一页选题说明）：
  - 三道题的六项清单评分；
  - 选定理由与放弃理由各一条；
  - **选定题的 2–3 个预演建法**——直接供 Stage 2 机制一使用，不浪费。

## 八、年度更新

每年赛后补一行到第二节表格，并**重新判断第三节的规律强度分层是否仍成立**。规律会失效（2025 B 题即为例证），本节结论不得沿用。

## 九、本阶段不做什么

- 不做详细建模（那是 Stage 2）。
- 不读取题型 playbook（路由在 Stage 1 按数学结构做，不按题号做）。
- 不因「往年这题获奖率高」选题——评奖看论文本身，不看题号。
